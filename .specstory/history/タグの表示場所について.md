_**Assistant**_

tag_todoピボットテーブルは、TodoとTagの間の多対多（Many-to-Many）の関係を管理するためのテーブルです。

具体的には：

1. 1つのTodoに複数のタグを付けることができる
2. 1つのタグを複数のTodoに付けることができる

という関係を実現するために必要です。

例えば：
- 「買い物」というTodoに「急ぎ」「家事」というタグを付ける
- 「レポート作成」というTodoに「急ぎ」「仕事」というタグを付ける

このような場合：
- 「急ぎ」タグは複数のTodo（買い物、レポート作成）に付いている
- 「買い物」というTodoには複数のタグ（急ぎ、家事）が付いている

このような多対多の関係を実現するために、tag_todoテーブルでは：
```php
$table->foreignId('tag_id')->constrained()->onDelete('cascade');  // どのタグか
$table->foreignId('todo_id')->constrained()->onDelete('cascade'); // どのTodoか
$table->unique(['tag_id', 'todo_id']);                           // 同じタグを同じTodoに重複して付けられないようにする
```

という構造になっています。

これにより：
1. タグとTodoの紐付けを保存できる
2. 1つのTodoに複数のタグを付けられる
3. 1つのタグを複数のTodoで使い回せる
4. タグやTodoが削除された時、関連する紐付けも自動的に削除される（`onDelete('cascade')`）

という機能が実現できます。

+     public function getTaskStatistics(int $userId): array
+     {
+         $todos = Todo::where('user_id', $userId);
+         
+         return [
+             'total' => $todos->count(),
+             'in_progress' => $todos->where('status', 'in_progress')->count(),
+             'completed' => $todos->where('status', 'completed')->count(),
+             'overdue' => $todos->where('status', 'in_progress')
+                 ->where('deadline', '<', Carbon::now())
+                 ->count(),
+         ];
+     }
+ 
+     /**
+      * タスク進捗状況のグラフデータを生成
+      */
+     public function getProgressChartData(int $userId): array
+     {
+         $todos = Todo::where('user_id', $userId)->get();
+         
+         $inProgress = $todos->where('status', 'in_progress')->count();
+         $completed = $todos->where('status', 'completed')->count();
+         $overdue = $todos->where('status', 'in_progress')
+             ->where('deadline', '<', Carbon::now())
+             ->count();
+ 
+         return [
+             'labels' => ['進行中', '完了', '期限超過'],
+             'data' => [$inProgress, $completed, $overdue],
+             'backgroundColor' => ['#3498db', '#2ecc71', '#e74c3c'],
+         ];
+     }
+ 
+     /**
+      * タグ別のタスク数を取得
+      */
+     public function getTagStatistics(int $userId): array
+     {
+         return Tag::where('user_id', $userId)
+             ->withCount(['todos' => function ($query) use ($userId) {
+                 $query->where('user_id', $userId);
+             }])
+             ->orderByDesc('todos_count')
+             ->limit(10)
+             ->get()
+             ->map(function ($tag) {
+                 return [
+                     'name' => $tag->name,
+                     'count' => $tag->todos_count,
+                 ];
+             })
+             ->toArray();
+     }
+ 
+     /**
+      * 今後の締め切りタスクを取得
+      */
+     public function getUpcomingDeadlines(int $userId): Collection
+     {
+         return Todo::where('user_id', $userId)
+             ->where('status', 'in_progress')
+             ->where('deadline', '>=', Carbon::now())
+             ->orderBy('deadline')
+             ->limit(5)
+             ->get();
+     }
+ 
+     /**
+      * 日別タスク作成数の推移データを取得
+      */
+     public function getDailyTaskCreationData(int $userId): array
+     {
+         $startDate = Carbon::now()->subDays(13);
+         
+         $dailyCounts = Todo::where('user_id', $userId)
+             ->where('created_at', '>=', $startDate)
+             ->select(DB::raw('DATE(created_at) as date'), DB::raw('COUNT(*) as count'))
+             ->groupBy('date')
+             ->orderBy('date')
+             ->get()
+             ->pluck('count', 'date')
+             ->toArray();
+ 
+         $labels = [];
+         $data = [];
+         
+         for ($i = 0; $i < 14; $i++) {
+             $date = $startDate->copy()->addDays($i)->format('Y-m-d');
+             $labels[] = $date;
+             $data[] = $dailyCounts[$date] ?? 0;
+         }
+ 
+         return [
+             'labels' => $labels,
+             'data' => $data,
+         ];
+     }
+ }
